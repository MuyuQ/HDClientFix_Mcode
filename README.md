# WDM 中文交通提示

将 WDM 世界地图中的船只和飞艇目的地提示显示为中文，共覆盖 19 种提示。例如 `Zeppelin to Brill` 显示为“前往布瑞尔的飞艇”。

## 安装与关闭

完全退出游戏，将 `WDM_ZH_Mcode` 文件夹复制到 `Wow.exe` 所在目录的 `Interface\AddOns`，然后重新启动游戏。在角色选择界面的插件列表中启用“WDM 中文交通提示”，内置 WDM 继续启用。

首次安装需完全重启；更新已经安装的 Lua 文件后通常可 `/reload`。关闭时禁用本插件并 `/reload`，提示恢复为 WDM 原有文字。

## 范围

需要当前 HD 客户端内置的 WDM 1.0.5。本插件保留 WDM 的地图、图标、坐标和交互，只补译已知的船只与飞艇提示；飞行点、地下城名称和未知文字沿用 WDM 的显示。WDM 未加载时不安装文字处理。

本插件独立打包，不自动加入整体汉化分发。语法和 Lua 5.1 模拟检查通过后仍需在游戏中悬停标记、切换地图并重新悬停，确认实际显示。

## 维护

WDM 在加载 `_data.lua` 时缓存语言表的文字，随后 `AtlasPOI:ShowPOIs()` 每次刷新都会重写标记名称。补丁通过该方法的后置钩子修改 `WorldMapFrameAtlasPOI` 标记的 `name`；原生悬停函数继续读取它。只改运行时语言表不能更新已缓存的名称。
