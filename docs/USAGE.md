# HD 客户端修复使用说明

[返回项目首页](../README.md) · [更新记录](../CHANGELOG.md)

`HDClientFix_Mcode` 合并原 `CharPanelFix_Mcode` 的角色与窗口修复，以及 `WDM_ZH_Mcode` 的地图交通提示汉化。
角色面板修复沿用 Mcode 的实现，地图交通提示汉化由 MuyuQ 提供。
感谢提供截图、实测和问题反馈的玩家。
角色面板、其他窗口与提示、地图交通提示的使用方法统一在本说明维护。
插件目录为 `Interface\AddOns\HDClientFix_Mcode\`，版本查看该目录中的 `HDClientFix_Mcode.toc`。

## 安装与升级

1. 完全退出游戏与启动器。
2. 在 `Interface\AddOns\` 删除 `CharPanelFix_Mcode`、`WDM_ZH_Mcode` 和仍存在的 `Mcode_CharPanelFix` 目录，保留 WDM 本体、ElvUI 及其他依赖插件。
3. 安装完整的 `HDClientFix_Mcode` 目录。已有同名新版目录时，备份后完整替换，避免残留旧文件。
4. 完全重启游戏，在插件列表启用新插件；输入 `/hdfix` 检查依赖状态并按需要设置功能开关。

无需复制、改名或迁移旧插件存档，`WTF` 中的账号文件不必处理。
新版已有设置继续使用；各项开关以新插件设置页为准。
复制新目录不会删除不同名称的旧目录，必须按上面的列表清理。
检测到旧插件冲突时，聊天框会分行提示一次；`/hdfix` 设置页会说明受影响的功能和处理方法。
冲突只暂停新插件中对应的模块，不会删除旧目录。请退出游戏，移出旧目录后完全重启。

`20261014` 历史分发快照保留合并前插件。
当前整体分发使用合并后的外置插件；具体组件见《用户说明.md》《修复列表.md》。

## 打开设置

输入 `/hdfix`，或打开 **ESC → 界面 → 插件 → HD 客户端修复**。
一个设置页按“角色面板”“其他窗口与提示”“地图”分组，可滚动阅读。
没有额外总开关；每项保留自己的开关，设置随正常重载或退出游戏保存。
缺少依赖时显示原因，相应选项暂不可操作；依赖就绪后重新打开设置即可。
战斗中输入 `/hdfix` 只提示稍后查看，不打开界面。
战斗期间设置页和 `/cpfix on/off` 不修改修复选项，需等战斗结束；周期施加延后处理。
若发现来自更高版本的存档，会保留原数据并暂停修复，请安装对应版本。

## 角色面板

主要角色面板修复要求 **ElvUI＋ElvUI_Enhanced，并启用 Enhanced 的角色面板模块**。
仅安装 ElvUI 核心不够；条件不满足时不接管原有角色面板。
设置页显示“未加载 ElvUI”“未加载 ElvUI_Enhanced 角色面板模块”“模块未启用”或依赖已就绪。

| 选项 | 命令组件名 | 默认状态 | 作用或关闭后的处理 |
|---|---|---|---|
| 为新角色补开 Enhanced 角色面板 | `enhancedEnable` | 开 | 只补充档案中尚未设置的开关；尊重明确的 false。关闭后停止补充，已开启的模块须在 ElvUI 中关闭 |
| 侧栏互斥 | `sidebar` | 开 | 避免属性、称号与装备管理侧栏同时显示；关闭后重载 |
| 默认显示属性页 | `sidebarDefaultToStats` | 开 | 依赖侧栏修复 |
| 隐藏重复装等与 GS 文字 | `clientGS` | 开 | 保留 GearScoreLite 的数据处理；关闭后重载 |
| 统一平均物品等级 | `itemLevel` | 开 | 优先读取客户端有效装等文本；无有效值时按实际装备件数计算，显示整数 |
| 隐藏重复属性面板 | `clientStatPanels` | 开 | 关闭后重载 |
| 隐藏重复切换按钮 | `clientToggleButtons` | 开 | 关闭后重载 |
| 角色模型显示 | `model` | 开 | 关闭后重载 |
| 角色模型拖动与缩放 | `modelControls` | 开 | 关闭时移除本插件安装的交互 |
| 种族背景 | `modelFeatures` | 开 | 只补充一次；已有背景在 ElvUI 设置中调整 |
| 客户端面板底图 | `clientPanelArt` | 关 | 与 ElvUI 半透明面板属于不同风格；关闭后收回本插件创建的贴图 |
| 称号与公会名字重叠 | `clientTitles` | 开 | 关闭后重载 |
| 隐藏客户端原称号控件 | `clientTitleWidgets` | 关 | 关闭后重载 |
| 属性行距与装等字号 | `enhancedGeometry` | 开 | 关闭后重载 |
| 底部标签行位置 | `tabAnchor` | 开 | 需要 ElvUI 角色窗口底框，不要求 Enhanced；关闭后重载 |

“为新角色补开”只需要 Enhanced 模块已加载，模块关闭时仍可调整这个修复开关。
它不会替你重新开启明确关闭的 Enhanced 模块。

### 新角色与旧角色表现不同

Enhanced 的角色面板开关是逐角色设置，旧角色的开关不会自动成为新角色的开关。
新角色缺少属性栏、侧栏按钮或出现模型叠影时，先在 `/hdfix` 检查依赖与模块状态。
“为新角色补开”只为档案中没有显式值的角色补充开启；明确关闭的值保持关闭。
关闭这个修复项不会撤销已补开的模块，需在 ElvUI 设置中自行关闭。

### 装等与 GS 的区别

物品等级行显示整数，直接截去小数，例如 `273.4` 显示为 `273`。
插件优先读取客户端 `PGearScore` 中有效的装等数字；该值缺失或为 0 时，按 1–18 栏位中能取得物品等级的装备平均，排除衬衣栏位 4，空栏不计入分母。
关闭装等修复时会恢复原显示方法，无需重载；重复装等块仍由独立的 `clientGS` 开关控制。
启用装等修复后，本次登录会展开“物品等级”分类一次，并更新 ElvUI 的折叠设置；之后仍可手动折叠。

角色面板上的 GS 数字、标签和重复装等块由 `clientGS` 控制隐藏，GearScoreLite 的数据处理仍保留。
`selfGS` 只在悬停自己时补充 GS 提示，需要 GearScoreLite；它不恢复角色面板上的 GS 标签，沿用 GearScoreLite 的战斗门控，已有 GS 行时不重复添加。
GearScoreLite 不是主要角色面板修复的必装依赖；没有它时不补自己的 GS 提示行。

### 模型交互与背景

角色模型交互包括滚轮缩放、左键拖动旋转和右键拖动平移，启用时补装客户端原有交互函数。
如果已启用 Enhanced 的模型交互，插件让位，不再安装自己的交互；试衣间拖转也会检查现有鼠标处理。
关闭模型交互时只恢复本插件接管的脚本；其他插件后来接管时会让位，保留其处理器。
种族背景只补充一次，之后在 ElvUI 中手动调整不会被反复覆盖。
客户端面板底图默认关闭；它与 ElvUI 半透明底框属于不同风格，可按喜好选择。

## 地图

工程内 b092 沿用现成中文贴图的厄运之槌室外独立地图；地图贴图、区域关联和缩小或右键返回菲拉斯的逻辑均由汉化 MPQ 提供。HDClientFix 2.0.7 不再加载地图导航模块，也不新增地区菜单项。身处室外区域按 M 应打开独立室外图，副本内部仍使用原来的地图。

本项为 b092 本地更新，既有 20261023 分发快照仍为 b091 / HDClientFix 2.0.6。中文地图显示效果已由用户确认；迁移后的实际加载、返回及进出副本仍待游戏复测。修改 MPQ 与移除旧模块后须完全退出并重启客户端，仅 /reload 不足以验收。

### 厄运之槌室外地图检查

1. 在菲拉斯的厄运之槌室外区域按 M，确认打开独立的室外地图，而不是卡利姆多或普通菲拉斯地图；检查地图标题和地名显示为中文。
2. 在室外地图上分别点击“缩小”和右键，确认都返回菲拉斯。
3. 进入厄运之槌副本，确认内部地图和楼层仍正常；离开副本后再按 M，确认回到室外地图。
4. 确认地区下拉框不再新增专用入口；可关闭 HDClientFix 后重启，复测室外图的返回行为仍正常。

当前支持本 HD 客户端内置 WDM 1.0.5 的交通提示；不替换 WDM 本体，也不修改地图 MPQ。

“汉化船只与飞艇目的地提示”默认开启，覆盖当前 HD 客户端内置 WDM 的 19 种提示。
例如 `Zeppelin to Brill` 显示为“前往布瑞尔的飞艇”。
不依赖 ElvUI；WDM 或其 AtlasPOI 模块未加载时不处理地图。
切换地图及重复刷新后继续补译。
飞行点、地下城名称、未知文字和原生标记沿用 WDM 的显示；坐标、图标和点击操作保持原有行为。
开关即时生效：关闭后恢复本插件替换前的文字，开启后重新补译当前标记。
其他插件随后修改的文字不会被本插件的关闭操作覆盖。

### 检查地图提示是否生效

1. 在“地图”分组确认 WDM 依赖就绪，并启用交通提示汉化。
2. 打开世界地图，悬停格罗姆高的布瑞尔飞艇标记，检查是否显示“前往布瑞尔的飞艇”。
3. 切到其他地图再返回，确认仍显示中文。
4. 关闭地图汉化，检查被本插件替换的文字恢复原文，再开启确认重新补译。

如果其他插件后来改写了提示，关闭本插件不会覆盖那份后来的文字。

## 排查与反馈

先在 `/hdfix` 核对功能开关、依赖状态和旧插件冲突，再打开出问题的角色面板或试衣间。
角色面板仍有重叠、模型缺失、武器栏消失或装备提示被遮挡时，输入 `/cpfix dump`，复制输出并附截图、角色、操作步骤和插件版本。
输出会列出可见控件及其父级、锚点、模型单位、模块状态、实际行高和字号；模型的子对象也会列出，便于确认装备槽位是否挂在模型下面。
排查时一次关闭一个相关组件；标有需重载的项关闭后输入 `/reload` 再比较，不能只凭即时画面判断回退是否完成。

字体兼容项默认关闭，只在 LibSharedMedia 存在时注册 `AvantGarde LT Medium` 与 `AvantGarde LT Bold` 的中文字体兼容名称。
它不提供新的字体资源；文字重叠先检查字体、行距和相关组件，不必为了显示中文开启全部修复。
屏幕上的 WeakAuras 文字或广告光环不由本插件清理，请在对应光环配置中排查。

### 维护时保留的注意事项

客户端的 `CharacterModelFrame` 与 `CharacterModelFrame2` 原本就是两张模型，不能把这对对象直接判为 XML 重复加载。
重复模型可能挂着主手、副手、远程与弹药槽位，隐藏父对象会一起隐藏这些槽位；排错需同时查看父级、子对象和层级。
模型遮住装备提示时，还要检查鼠标处理与框体层级，不能只比较坐标。
客户端异名属性容器须按前缀和父级核对，避免漏掉重复面板或隐藏其他窗口的同名前缀控件。

## 原命令与回退

原 `/cpfix on <组件>`、`/cpfix off <组件>`、`/cpfix dump` 和 `/cpfix reload` 继续可用。
`/cpfix` 查看组件开关状态；表中的“命令组件名”用于单独开关，例如：

```text
/cpfix off modelControls
/cpfix on modelControls
/cpfix off itemLevel
/cpfix dump
```

地图开关通过 `/hdfix` 的“地图”分组调整。
`/cpfix reload` 表示重新施加修复，完整重载界面须输入 `/reload`。
界面与命令使用相同设置；角色范围内的关闭项只影响该角色，其他细项沿用账号共享设置。

回退前完全退出游戏，移出新插件，恢复旧插件目录和备份的旧插件列表。
旧账号存档没有删除；合并后新增设置不会自动回写旧插件。
语法、模拟行为与文件校验不代表真实游戏已验收；字体、缩放、滚动、地图悬停和关闭恢复仍需游戏内复验。
